# Plan: device-source port + `acquire` / `unpack` stages (Unity 6 inventory)

## Audit (current state)
- Foundation only: `STAGE_MODULES = ()`, no adapters, `zk/formats` empty, `[adapters] device_source` commented out, no `package` in `zk.toml`.
- Port `device_source` v1: `pull(package, dest) -> dict`, CONTRACT `files=("base.apk",)`. Problem: the version label (`versionName-versionCode`) must be known **before** choosing `raw/<v>/`, and the existing layout is `raw/<v>/apk/base.apk`. So the contract needs amending, and the ADR rule says that needs a new ADR.
- No phase progress recorded; nothing implemented yet.
- Probe data (`raw/0.4.6-17/probe`) shows facts the plan must handle: `globalgamemanagers.assets.split0..9` (Unity split files: count as one logical file, header in `split0`), `level0`, `sharedassets0.assets`, `<hash>` + `<hash>.resource` pairs. `ScriptingAssemblies.json` `types`: 2 = engine module, 16 = user/package assemblies (all `Unity.*`, `System.*` and `ZodiacKnights.*` are 16), so game assemblies = type 16 minus `Unity*`/`System*`/`Mono*`/`mscorlib`/`netstandard` prefixes. `assets/Video/manifest.json` lists 9 clips.

## Design decisions
1. **ADR 0002: device_source contract v2.** The Protocol becomes:
   ```python
   class DeviceSource(Protocol):
       def identify(self, package: str) -> dict: ...   # {"package", "version", "abi"?}; RuntimeError if not installed
       def pull(self, package: str, dest: Path) -> dict: ...  # writes dest/apk/*.apk, optional dest/obb/, dest/data/
   CONTRACT = ArtifactContract(PORT, files=("apk/base.apk",))
   ```
   This keeps the SSA layout (`raw/<v>/apk/base.apk`) that matches the existing raw folder.
2. **Adapter options in config**: a new top-level `[options.<port>]` table → `Config.options: dict[str, dict[str, str]]`. Unknown port names are rejected, like `[adapters]`. The folder adapter reads `path` and `version` from `[options.device_source]`. This is needed because the folder source has no device to ask for a version, and the stage must not know which adapter is in use.
3. Package lives in config: `package = "com.zodiacknights.game"` in `zk.toml`, with an `acquire --package` override. No package list is hard-coded.
4. adb runs through Python `subprocess` (no MSYS), so `MSYS_NO_PATHCONV` isn't needed. Destination paths are passed as native `str(Path)`. The docs note the Git Bash caveat for manual pulls. Multiple ready devices with no `ANDROID_SERIAL` → clear `RuntimeError` (adb honours that env var natively).
5. Known metadata versions: `KNOWN_VERSIONS = frozenset({39})`, i.e. only versions this pipeline was checked against. Other versions → a warning in the manifest, not a crash. A bad magic → `encrypted=True` plus a warning.
6. Docs filename: keep `docs/ports/device_source.md` (it matches the port name and the other 4 port pages, and `index.md` already links it). The criterion's `device-source.md` is read as this page. If the user wants the hyphenated name, that needs a phase edit, not a duplicate file.

## Files
- `docs/adr/0002-device-source-v2.md` (new): why `identify` + `apk/base.apk`.
- `src/zk/ports/device_source.py`: Protocol + CONTRACT v2.
- `src/zk/core/config.py`: `options` key/field + validation; `zk.toml`: `package`, `device_source = "adb"`, commented `[options.device_source]` example.
- `src/zk/adapters/adb.py` (new): `PORT`, `create(cfg)`, `AdbSource(adb_path, sh)` where the `sh` runner is injected for tests. Pure helpers ported from SSA `acquire.py`: `parse_devices`, `parse_pm_path`, `parse_version`. Plus `identify` (devices check → `pm list packages` → `dumpsys package` → `versionName-versionCode`, `getprop ro.product.cpu.abi`) and `pull` (every split from `pm path` into `dest/apk/`, `/sdcard/Android/data/<pkg>` into `dest/data/` with a `CalledProcessError` → `data: false`, OBB tried the same way). Uses `toolchain.adb()` / `toolchain.run`.
- `src/zk/adapters/folder.py` (new): ported from SSA `import_.py`. `identify` returns the configured `version` (RuntimeError if `path`/`version` is unset or the path is missing). `pull` copies `.apk` → `apk/`, `.obb` → `obb/`, everything else → `data/`. A single `.apk` source is stored as `apk/base.apk`; a folder with no `base.apk` → RuntimeError. Sorted iteration.
- `src/zk/formats/il2cpp_metadata.py` (new): `MAGIC = 0xFAB11BAF`, `KNOWN_VERSIONS`, `parse_header(data: bytes) -> MetadataHeader(magic, version, encrypted, warnings)` (frozen dataclass; <8 bytes → encrypted with a warning).
- `src/zk/formats/unity_serialized.py` (new): `parse_header(head: bytes) -> SerializedHeader | None` (format at 0x08 BE; version string at 0x14 for formats 9–21, at 0x30 for 22–40, regex `(\d{4}|\d)\.\d+\.\d+[a-z]\d+\0`), `is_serialized_file(head) -> bool`.
- `src/zk/formats/scripting_assemblies.py` (new): `parse(text: str) -> ScriptingAssemblies(names, types)` with length checks; `game_assemblies(sa) -> list[str]` (type 16, non-Unity/System prefixes, `.dll` stripped, sorted).
- `src/zk/stages/acquire.py` (new): `NAME="acquire"`, args `--package`, `--force`. `src = ctx.adapter("device_source")` → `identify` → validate the label (`^[\w.+-]+$`, no path separators) → `dest = ws.dir("raw", v)`. Skip the pull if `apk/base.apk` exists and there's no `--force`. Otherwise `pull`, then `CONTRACT.verify(dest)`, sha256 + size of `base.apk` (streamed), `record_facts({"version", "package"})`. Returns `{package, version, abi, pulled, base_apk: {sha256, bytes}, path}`.
- `src/zk/stages/unpack.py` (new): `NAME="unpack"`, `--force`. Extracts each `raw/<v>/apk/*.apk` to `unpacked/<v>/<stem>/` (skipped if present). `inventory(root) -> dict` built from:
  - `abis` (sorted dirs under `lib/` holding `libil2cpp.so`), `il2cpp` {abi: rel path}, and `backend` (`il2cpp` / `mono` / `unknown`);
  - `metadata` {path, magic hex, version, encrypted};
  - `unity_version` + `serialized_format` from `assets/bin/Data/globalgamemanagers`;
  - `assemblies` {count, game};
  - `serialized_files` count (`.splitN` grouped, header from `split0`), `resource_streams` count (`.resource`/`.resS`);
  - `videos` (sorted names under `assets/Video` with sizes, plus `manifest_json: bool`);
  - `warnings` list (missing ggm/metadata/ScriptingAssemblies, unknown metadata version, bad magic).

  It records facts `unity_version`, `metadata_version`, `backend`, `abis` and returns `{version, **inventory}`. Ported from SSA `unpack.py` `inventory`; bundles/Lua/`layout.py` dropped.
- `src/zk/stages/__init__.py`: `STAGE_MODULES = ("acquire", "unpack")`.
- Tests (new, synthetic only): `tests/test_formats.py` (metadata: good/v39, unknown version → warning, bad magic, short; serialized: fmt 22 @0x30, fmt 17 @0x14, garbage, short; scripting assemblies: game filter, mismatched lengths → ValueError). `tests/test_adb_adapter.py` (parsers; identify/pull with a fake `sh`/`run`: no device, unauthorized, package missing, multi-split, data pull failure tolerated). `tests/test_folder_adapter.py`. `tests/test_stages_acquire_unpack.py` (fake `tests/fakes/fake_device.py` adapter writes a synthetic zip APK containing lib/{3 ABIs}/libil2cpp.so, metadata, ggm fmt 22 "6000.3.2f1", split files, `.resource`, ScriptingAssemblies.json, Video/*; runs `cli.main(["acquire"])` then `["unpack"]` and asserts manifest fields + facts; the label is validated). Update `tests/test_config.py` for `options`.
- Docs: `docs/ports/device_source.md` (v2 Protocol, contract, adb + folder adapters, options, Git Bash caveat), `docs/stages/acquire.md`, `docs/stages/unpack.md` (inputs, outputs, every manifest field, failure modes, tests), `docs/formats/{il2cpp_metadata,unity_serialized,scripting_assemblies}.md`, links in `docs/index.md`, ADR link in `docs/architecture.md` and a manifest example update.

## Risks
- Real-device criterion (`zk acquire` sha256 == `raw/0.4.6-17/apk/base.apk`, label `0.4.6-17`) needs the phone plugged in with USB debugging authorised. If it isn't, report `blocked` asking the user to connect it; everything else is still done.
- Extracting a 390 MB APK takes disk space (about 1 GB unpacked) and runs once; reruns skip it.
- The format upper bound of 40 and `KNOWN_VERSIONS` are conservative. Out-of-range values give warnings, never crashes.
- Boundary test: stages import only `zk.ports`, `zk.core.workspace`/`contracts` and `zk.formats`; adapters import `zk.core.toolchain`.
